# LVGL嵌入式UI框架详细设计文档

## 1. 项目概述

本框架是基于LVGL的嵌入式设备UI管理系统，解决以下核心问题：

- **页面生命周期管理**：统一管理页面的创建、显示、隐藏、销毁
- **导航栈管理**：支持页面跳转、返回、历史记录
- **数据与视图分离**：UI与业务数据解耦，支持多实例
- **线程安全通信**：设备线程与UI线程之间安全、高效的消息传递
- **动态设备管理**：支持设备的动态添加/移除，UI自动响应

## 2. 模块详细设计

### 2.1 页面模块 (Page)

```c
typedef enum {
```


**事件数据结构** (`event_bus.h:19-26`):
```c
typedef struct {
    EventType type;              // 事件类型
```

**事件总线结构体** (`event_bus.h:28-37`):
```c
typedef struct {
    Page* subscribers[MAX_EVENT_TYPES][MAX_SUBSCRIBERS_PER_EVENT]; // 订阅者二维数组
    int sub_count[MAX_EVENT_TYPES];              // 每种事件的订阅者数量
    Event queue[MAX_EVENT_QUEUE];                // 事件队列（环形缓冲区）
    int queue_head;                              // 队列头指针
    int queue_tail;                              // 队列尾指针
    int queue_count;                             // 队列中事件数量
```

#### 2.3.2 API接口

| 函数 | 参数 | 返回值 | 描述 |
|------|------|--------|------|
| `event_bus_init` | `void` | `void` | 初始化事件总线，创建定时任务（50ms） |
| `event_bus_subscribe` | `Page* page, EventType event` | `void` | 页面订阅事件 |
| `event_bus_unsubscribe` | `Page* page, EventType event` | `void` | 页面取消订阅事件 |
| `event_bus_unsubscribe_all` | `Page* page` | `void` | 页面取消所有订阅 |
| `event_bus_trigger` | `Event* event` | `void` | 触发事件（线程安全，非阻塞） |
| `event_bus_process` | `void` | `void` | 处理事件队列，分发给订阅者 |

#### 2.3.3 实现要点

- **订阅机制** (`event_bus.c:20-40`):
  - 每个事件类型维护最多10个订阅者
  - 订阅时检查重复订阅
  - 使用互斥锁保护订阅列表

- **事件触发流程** (`event_bus.c:82-94`):
  1. 获取互斥锁
  2. 事件加入环形队列
  3. 释放互斥锁
  4. 立即返回（非阻塞）

- **事件处理流程** (`event_bus.c:96-124`):
  1. LVGL定时任务每50ms调用`event_bus_process`
  2. 从队列取出一个事件
  3. 查找该事件的所有订阅者
  4. 调用每个订阅者的`on_event`回调

- **线程安全设计**:
  - 使用`lv_mutex_t`保护共享数据
  - 设备线程调用`event_bus_trigger`
  - UI线程调用`event_bus_process`

  - 设备线程处理命令并触发事件

- **设备移除处理**:
  - 设置`model->is_valid = 0`
  - 触发`EVENT_DEVICE_REMOVED`事件
  - 页面收到事件后清理UI，减少引用计数

## 3. 数据流和线程模型

### 3.1 线程划分

1. **UI线程 (LVGL主线程)**:
   - 运行LVGL主循环 (`lv_task_handler`)
   - 处理用户输入和UI渲染
   - 调用`event_bus_process`处理事件
   - 调用页面管理器导航功能

2. **设备线程**:
   - 轮询硬件状态
   - 处理命令队列
   - 调用`event_bus_trigger`发送事件

### 3.2 数据流示例（灯状态变化）

```
用户点击开关 → UI线程 → page_manager处理点击事件
    ↓
调用device_manager_send_command
    ↓
命令加入全局队列 → 设备线程处理队列
    ↓
更新LightModel状态
    ↓
event_bus_trigger(EVENT_LIGHT_STATE_CHANGED)
    ↓
事件加入队列 → LVGL定时任务调用event_bus_process
    ↓
查找订阅者 → 调用page->lifecycle.on_event
    ↓
更新UI显示状态
```

### 3.3 设备移除处理流程

```
设备线程检测设备移除 → model->is_valid = 0
    ↓
event_bus_trigger(EVENT_DEVICE_REMOVED)
    ↓
页面收到事件:
  1. page_set_model_valid(page, 0)
  2. model->ref_count--
  3. 清空model指针
  4. 显示"设备已移除"UI
  5. 禁用交互控件
    ↓
主页面收到事件:
  1. 从滑动容器移除对应tab
  2. 触发页面销毁
    ↓
页面销毁时:
  1. 取消所有事件订阅
  2. 释放页面数据
    ↓
model->ref_count == 0 → 可安全释放模型
```

## 4. API使用示例

### 4.1 基本使用流程

```c
// 1. 初始化框架
page_manager_init();
page_manager_set_cache_size(3);

// 2. 注册滑动容器实现
swipe_container_register("tileview", &g_tileview_ops);

// 3. 注册页面
page_manager_register("MainPage", main_page_create);
page_manager_register("LightPage", light_page_create);

// 4. 初始化事件总线
event_bus_init();

// 5. 创建设备管理器
DeviceManager* dm = device_manager_create();
device_manager_start(dm);

// 6. 打开首页
page_manager_open("MainPage", NULL);

// 7. LVGL主循环
while (1) {
    lv_task_handler();
    lv_thread_delay(5);
}
```

### 4.2 页面创建示例

```c
// 灯页面创建函数
static Page* light_page_create(void* params) {
    PageLifecycle cbs = {
        .on_create = light_page_on_create,
        .on_resume = light_page_on_resume,
        .on_event = light_page_on_event,
        .on_destroy = light_page_on_destroy
    };
    
    return page_create(&cbs, params);  // params为LightModel*
}

// 事件处理函数
static void light_page_on_event(Page* page, Event* event) {
    LightPageData* data = (LightPageData*)page_get_user_data(page);
    
    switch (event->type) {
        case EVENT_LIGHT_STATE_CHANGED:
            // 更新UI状态
            break;
        case EVENT_DEVICE_REMOVED:
            // 处理设备移除
            page_set_model_valid(page, 0);
            break;
    }
}
```

### 4.3 设备命令发送

```c
// 开关点击处理
static void on_switch_click(lv_obj_t* btn, lv_event_t event) {
    Page* page = (Page*)lv_obj_get_user_data(btn);
    
    if (!page_is_model_valid(page)) {
        // 显示错误提示
        return;
    }
    
    LightPageData* data = (LightPageData*)page_get_user_data(page);
    
    // 发送开关命令（0:开关命令，1:新状态）
    device_manager_send_command(g_dm, data->model->id, 0, !data->model->is_on);
    
    // UI立即反馈
    lv_label_set_text(data->btn_label, "发送中...");
}
```

## 6. 错误处理和调试

### 6.1 错误处理策略

1. **空指针检查**：所有公共API都进行空指针检查
2. **边界检查**：数组索引、栈操作进行边界检查
3. **资源释放**：确保分配的资源在销毁时正确释放
4. **线程安全**：共享数据使用互斥锁保护

### 6.2 调试支持

- **日志输出**：关键操作通过`printf`输出日志
- **状态检查**：`page_is_model_valid`检查模型有效性
- **断言**：可添加`assert`检查关键条件（当前未使用）

### 6.3 常见问题

1. **页面未注册**：`page_manager_open`时检查创建器是否存在
2. **事件丢失**：事件队列满时丢弃新事件（可记录日志）
3. **内存泄漏**：确保页面销毁时取消所有事件订阅
4. **线程死锁**：避免在事件回调中执行耗时操作

## 7. 扩展指南

### 7.1 添加新事件类型

1. 在`event_bus.h`的`EventType`枚举中添加新事件
2. 在`Event`联合体中添加对应的数据结构
3. 页面订阅新事件，在`on_event`中处理

### 7.2 添加新设备类型

1. 创建新的模型结构（如`FanModel`, `SensorModel`）
2. 扩展设备管理器支持新模型
3. 添加对应的事件类型
4. 创建专用页面显示和控制

### 7.3 添加新滑动容器实现

1. 实现`SwipeContainerOps`函数表
2. 调用`swipe_container_register`注册实现
3. 在创建容器时指定实现名称

### 7.4 性能优化建议

1. **减少事件频率**：避免高频事件触发
2. **优化UI更新**：批量更新UI，避免频繁重绘
3. **内存优化**：调整缓存大小，监控内存使用
4. **线程优先级**：根据系统调整线程优先级

## 8. 已知限制

1. **平台依赖**：依赖LVGL和其线程API
2. **内存固定**：使用固定大小数组，不支持动态扩展
3. **简化实现**：部分功能为简化实现（如缓存查找）
4. **错误恢复**：错误处理较为简单，未实现完整错误恢复机制
